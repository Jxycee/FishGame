# Fisher textures: sources and licences

The PNGs in this folder are generated by `Art/Blender/fg_fisher_tex.py` (stage `tex`) from the base maps below, then
stylised (high-pass, median-cleaned, soft-posterised, painted brush overlay, recoloured). They are derivative works;
no original pixels ship unmodified. Downloaded with `fg_fisher_tex.py fetch` from the Poly Haven API
(`https://api.polyhaven.com/files/<id>`, 1k PNG diffuse + GL normal). Licence for all: **CC0 1.0** (public domain,
commercial use allowed, no attribution required; credited anyway).
