**Decisions fixed here (B-D1..B-D18):**
- **B-D1** The resolver always makes the junk-share draw, even when the share is 0 (fixed draw count, so a hotspot or bait change never shifts later draws when the share is 0 either way).
- **B-D2** `Resolve`, `JunkShare` and the forced-junk path need `ZoneIndex` in range; `Resolve`/`JunkShare` also need `SubAreaIndex < zone.SubAreas.Count`. `AnySubArea` is for gates only (`Passes`, `CollectEligible`, `BitingNow`). Otherwise `ArgumentOutOfRangeException`.
- **B-D3** A pool rule whose weight works out non-positive or non-finite is skipped. A pool total that is not positive means an empty pool, which gives junk.
- **B-D4** Luck is sanitised before `CatchMath.RollFish`: NaN gives 0, then clamp to [-1, 1].
- **B-D5** `ForceJunk` wins over `ForcedItemIndex` (M2 precedence). Overrides draw only what they need (C 7.6). A forced item returns `ruleIndex = -1`.
- **B-D6** Bite-plan depth: +Infinity gives 6 (`FishingConstants.DepthMultFullDepth`), NaN gives 0. `eventMult = clamp(Events.BiteTimeMult, 0.5, 1.5)`, `skillMult = 1` (M4), hotspot x0.6 through `BitePlanner.WaitMultiplier`.
- **B-D7** `Passes`: a `Season` above Winter fails the season gate (no throw); NaN depth fails the depth gate; a `SubAreaIndex` of 8 or more (other than `AnySubArea`) fails a non-zero mask.
- **B-D8** `new EcologyRunState(seed)` sets `Season = (Season)Rng.Stream(seed, EcologyStreams.Season, 0).Range(0, 4)` (the `WeatherDirector.RollSeason` formula, inlined because T7 comes later; a T7 test pins the equality), `Day = 1`, `HostCastCounter = 0`.
- **B-D9** `ClockMath`: elapsed time is clamped at 0 (a client's server time can trail the anchor). A non-finite `serverTime` or `AnchorServerTime` returns `AnchorMinute`. A non-finite or negative rate counts as 0. `AnchorMinute` is clamped to [0, 1200], NaN gives 0. The sum is computed in double.
- **B-D10** `HotspotPlanner` is schedule-driven. A hotspot spawns at its scheduled minute, not at the observed one, so the step size never changes the schedule. A call can spawn and end several hotspots (catch-up loop). `Advance` is monotonic: an earlier minute does nothing. An ended hotspot leaves `Current = default`. With no candidate cells, nothing is ever scheduled (not even after a `ForceAt` ends).
- **B-D11** `WeatherDirector` validates its table in the constructor: `Base` has 9 finite entries >= 0, each row sum > 0, and `SeasonColumnMult` has 12 finite entries > 0; otherwise `ArgumentException`. Days are capped at 10,000 (`ArgumentOutOfRangeException`).
- **B-D12** `DayNightMath.Blend`: the starts must be strictly increasing (`ArgumentException`). The blend window into phase i is `min(window, nextStart - start_i)`, with `nextStart = 1` after the last phase, so a short phase finishes its blend before the next one starts (no pop). When `From == To`, `T = 0`.
- **B-D13** The sun arc peaks at 60 degrees elevation (a private constant). Azimuth runs east (+x) at sunrise, south (-z) at noon, west (-x) at sunset. Outside daylight the direction is clamped to the sunrise or sunset position; T18 uses the moon rotation there.
- **B-D14** Sun and moon weights fade with smoothstep over `flipWindow` on each side of the flip. They are never both non-zero, and both are 0 exactly at sunrise and sunset.
- **B-D15** Journal: bests update only on a strictly heavier local catch. PersonalBest needs an earlier catch. Counters saturate at `int.MaxValue`. A null or empty `spotId` is not recorded. `Apply` creates an entry only when `ShouldJournal` is true.
- **B-D16** `SilhouetteMath` shape table (T8).
- **B-D17** `DayClock.FormatTime` clamps the minute to 0..1199.
- **B-D18** `ZoneData` requires the first band to start at 0, each band to start where the previous one ends, `Max > Min`, and the last `MaxShoreM` to be +Infinity. Weather arrays are copied, not validated (`WeatherDirector` validates them).

### Behaviour
- **Enums, structs, interface:** copy C 7.5 and C 5.2 verbatim: names, underlying types, explicit values, field order, comments. Structs have public fields and no tuning initialisers. `EcologyConstants` and `EcologyStreams` are byte-identical to C 5.2. `EventMods.Neutral` / `SkillMods.Neutral` are `static readonly` with every field 1.
- **`EcologyMasks`:** `Of(s)` = `(SeasonMask)(1 << (int)s)` for Spring..Winter, else `ArgumentOutOfRangeException`. `WeatherColumn`: Clear 0, Rain 1, Fog 2; any other value (combined bits, None, Storm, Heatwave) gives `ArgumentException`.
- **`DayClock`** (C 5.2 comments are the spec):
  - `BandAt(m)`: clamp m to 0..1199, return the bit of the last `BandStart[i] <= m`.
  - `SegmentAt(m)`: clamp to 0..1199, then `/ 240`.
  - `DayFraction(m)`: NaN gives 0, else `clamp01(m / 1200)`.
  - `FormatTime(m)` (B-D17): clamp to 0..1199; `total = 360 + (m / 10) * 10`; `h24 = (total / 60) % 24`; `h12 = h24 % 12 == 0 ? 12 : h24 % 12`; text `h12 + ":" + (total % 60).ToString("00", CultureInfo.InvariantCulture) + (h24 < 12 ? " AM" : " PM")`.
- **`ClockMath`** (B-D9, spec 14.2):
  - `MinuteAt`: `m0 = clamp(AnchorMinute, 0, 1200)` (NaN gives 0). If `!Running`, the rate is not finite or not > 0, or either time is not finite, return `m0`. Else `elapsed = max(0, serverTime - AnchorServerTime)` and return `(float)min(1200, m0 + elapsed * rate)`, computed in double.
  - `At(t, minute, rate, running)` stores `t`, `clamp(minute, 0, 1200)` (NaN gives 0), the rate (non-finite or negative gives 0) and `running`.
  - `Reanchor(a, t, rate, running)` = `At(t, MinuteAt(a, t), rate, running)`. Continuity is exact by construction.
- **`BaitMods.Neutral(r)`:** `Rating = r`, `AffinityTags = None`, the three multipliers 1. **`BaitStats.Mods(n)`** (shared edit): `Rating = EffRating(n)`, `AffinityTags`, `AffinityMult`, `JunkMult` and `SpecialMult` copied.
- **`EventMods.WeightFor(tags)`:** the product of `NocturnalMult`, `PredatorMult`, `BottomMult`, `SchoolingMult` and `SurfaceMult` for the set bits; None gives 1. **`IsValid`:** all 8 fields finite and > 0. **`SkillMods.RarityMult`:** `UncommonRareMult` for Uncommon and Rare, else 1. `IsValid`: finite and > 0.
- **`ZoneData`** (B-D18):
  - Copies every array and exposes them through `Array.AsReadOnly`. `Weather` is `ref readonly` over a private copy whose arrays are cloned when non-null.
  - `ArgumentNullException` for null sub-areas, rules or junk. `ArgumentException` for: no sub-areas; more than `MaxSubAreas`; a broken band chain (B-D18); empty junk. Rules may be empty. The grid may be null.
  - `SubAreaIndexFor(s)`: NaN or +Infinity gives the last band; `s < 0` gives 0; otherwise the band with `Min <= s < Max`.
- **`EcologyDatabase`:** copies arrays. `ArgumentNullException` for null fishing, zones or spots (an `ArgumentException` subtype, as C 7.5 requires). `ArgumentException` for: a null zone; a rule `SpeciesIndex >= fishing.Species.Count`; a junk `JunkIndex >= fishing.Junk.Count`; a spot `ZoneIndex` outside the zones. `Tuning` is `ref readonly`.
- **`CatchLedger`:** two `Dictionary<ushort, int>` (caught, reserved).
  - `AtLimit(i, limit)`: `limit < 0` gives false; else `Caught + Reserved >= limit`.
  - `Reserve` increments reserved (no limit check: the host calls `Passes` first). `Commit` moves one reservation to caught. `Release` drops one.
  - `Commit` and `Release` with no reservation throw `InvalidOperationException` before any change.
  - `Clear` empties both.
  - No allocation on an existing key (T13's ledger `Tick` zero-alloc test runs releases): indexer updates only, no LINQ; `ushort` keys use the default comparer (no boxing). A new key may grow the dictionary.
- **`EcologyRunState`** (B-D8): `RunSeed`; `Season` rolled in the constructor with the inlined formula; `Day = 1`; `HostCastCounter = 0`; `Catches = new CatchLedger()`. Season and Day are settable.
- **`ShoreGrid`:**
  - Constructor: `ArgumentException` for `width < 1` or `height < 1`; for `cellSizeM` not finite or not > 0; for non-finite origins; when `shoreDm.Length != w*h`; when either bit array's length is not `(w*h + 7) / 8`. Null arrays give `ArgumentNullException`. Arrays are copied.
  - `TryCell`: false for non-finite input. In double, `fx = (x - OriginX) / CellSizeM`; `cx = floor(fx)`; true only for `0 <= cx < Width` and `0 <= cz < Height`.
  - `CellCentre`: `x = OriginX + (cx + 0.5f) * CellSizeM`, same for z.
  - `IsWater`: `TryCell` and `shoreDm[cz * Width + cx] != ShoreDmNotWater`. `ShoreM`: not water gives +Infinity, else `shoreDm / 10f`.
  - `IsCastable` / `IsReachable`: false outside the grid, else `GetBit` of the cell index.
  - `CollectReachableWaterCells(list)`: `ArgumentNullException` for null; clear the list; then add, in ascending index order, every cell that is water, castable and reachable.
  - `GetBit(packed, i)`: `(packed[i >> 3] >> (i & 7)) & 1`, LSB-first.
- **`IWorldContext`:** exactly C 7.5 (`using System;` for `Action`).

```csharp
// Core/Ecology/FishingResolver.cs: spec 12.4 gate and algorithm with a fixed draw order (C 7.6, M3-D12).
// Authority: host only for Resolve (FishingRoller inside FishingHostLedger). Passes/CollectEligible are pure and also feed the
// journal's "biting now" on every peer. Fixed draw order (seeds depend on it; FishingResolver_DrawOrder_HandReplayed):
//   1 junk-share draw (always, B-D1); 2 one draw per eligible special, in rule order, until the first success;
//   3 one pool draw (only when the pool is non-empty); 4 junk item draw (junk path) or CatchMath.RollFish (one draw). No allocation.
using System;
using System.Collections.Generic;

namespace FishGame.Core
{
    public sealed class FishingResolver
    {
        private readonly EcologyDatabase _db;

        public FishingResolver(EcologyDatabase db)
        {
            _db = db ?? throw new ArgumentNullException(nameof(db));
        }

        public CatchResult Resolve(in FishingContext ctx, ref Pcg32 rng, CatchLedger ledger)
        {
            return Resolve(in ctx, ref rng, ledger, out _, out _);
        }

        public CatchResult Resolve(in FishingContext ctx, ref Pcg32 rng, CatchLedger ledger, out float weightT, out int ruleIndex)
        {
            ZoneData zone = CheckedZone(in ctx, true);
            IReadOnlyList<SpawnRuleData> rules = zone.Rules;
            weightT = 0f;
            ruleIndex = -1;

            // 1. junk share: always one draw
            if (rng.NextFloat() < JunkShareOf(zone, in ctx)) return JunkItem(zone, ref rng);

            // 2. specials in rule order: one draw each until the first success
            float specialMult = ctx.Bait.SpecialMult * (ctx.InHotspot ? EcologyConstants.HotspotSpecialMult : 1f) * ctx.Events.RareChanceMult;
            for (int i = 0; i < rules.Count; i++)
            {
                SpawnRuleData r = rules[i];
                if (!r.Special || !Passes(in r, in ctx, ledger)) continue;
                float p = Math.Min(EcologyConstants.SpecialChanceCap, r.SpecialChance * specialMult);
                if (rng.NextFloat() < p)
                {
                    ruleIndex = i;
                    return Fish(r.SpeciesIndex, in ctx, ref rng, out weightT);
                }
            }

            // 3. weighted pool of eligible non-special rules; an empty pool gives junk (spec 12.4 step 4)
            float total = 0f;
            for (int i = 0; i < rules.Count; i++)
            {
                SpawnRuleData r = rules[i];
                total += PoolWeight(in r, in ctx, ledger);
            }
            if (!(total > 0f) || float.IsInfinity(total)) return JunkItem(zone, ref rng);

            // 4. one draw, walk in rule order (rounding past the end picks the last positive rule)
            float target = rng.NextFloat() * total, acc = 0f;
            int pick = -1;
            for (int i = 0; i < rules.Count; i++)
            {
                SpawnRuleData r = rules[i];
                float w = PoolWeight(in r, in ctx, ledger);
                if (w <= 0f) continue;
                pick = i;
                acc += w;
                if (target < acc) break;
            }
            ruleIndex = pick;
            return Fish(rules[pick].SpeciesIndex, in ctx, ref rng, out weightT);
        }

        // Spec 12.4 gate (C 7.6, B-D7). ledger null skips the catch limit.
        public bool Passes(in SpawnRuleData rule, in FishingContext ctx, CatchLedger ledger)
        {
            if (ctx.SubAreaIndex != EcologyConstants.AnySubArea && rule.SubAreaMask != 0)
            {
                if (ctx.SubAreaIndex >= EcologyConstants.MaxSubAreas || ((rule.SubAreaMask >> ctx.SubAreaIndex) & 1) == 0) return false;
            }
            if ((byte)ctx.Season > (byte)Season.Winter || (rule.Seasons & EcologyMasks.Of(ctx.Season)) == 0) return false;
            if ((rule.Weather & ctx.Weather) == 0) return false;
            if ((rule.Bands & DayClock.BandAt(ctx.Minute)) == 0) return false;
            if (ctx.RodTier < rule.MinRodTier) return false;
            if (ctx.Bait.Rating < rule.MinBaitRating) return false;
            if (!(ctx.Depth >= rule.MinDepth)) return false;                        // +Infinity passes, NaN fails
            if (ctx.PlayersInSession < rule.MinPlayersInSession) return false;
            if (ledger != null && ledger.AtLimit(rule.SpeciesIndex, rule.CatchLimitPerRun)) return false;
            return true;
        }

        public float JunkShare(in FishingContext ctx)
        {
            return JunkShareOf(CheckedZone(in ctx, true), in ctx);
        }

        public int CollectEligible(in FishingContext ctx, CatchLedger ledger, bool specials, List<int> ruleIndicesInto)
        {
            if (ruleIndicesInto == null) throw new ArgumentNullException(nameof(ruleIndicesInto));
            ruleIndicesInto.Clear();
            IReadOnlyList<SpawnRuleData> rules = CheckedZone(in ctx, false).Rules;
            for (int i = 0; i < rules.Count; i++)
            {
                SpawnRuleData r = rules[i];
                if (r.Special == specials && Passes(in r, in ctx, ledger)) ruleIndicesInto.Add(i);
            }
            return ruleIndicesInto.Count;
        }

        // FishingRoller's ForceJunk path: one junk item draw from the context's zone (sub-area not needed).
        internal CatchResult RollJunkItem(in FishingContext ctx, ref Pcg32 rng)
        {
            return JunkItem(CheckedZone(in ctx, false), ref rng);
        }

        // B-D4: NaN gives 0, then clamp to [-1, 1].
        internal static float SaneLuck(float luck)
        {
            if (float.IsNaN(luck)) return 0f;
            return luck < -1f ? -1f : (luck > 1f ? 1f : luck);
        }

        private ZoneData CheckedZone(in FishingContext ctx, bool forRoll)
        {
            if ((uint)ctx.ZoneIndex >= (uint)_db.Zones.Count)
                throw new ArgumentOutOfRangeException(nameof(ctx), "ZoneIndex " + ctx.ZoneIndex + " is not a zone index.");
            ZoneData zone = _db.Zones[ctx.ZoneIndex];
            if (!forRoll) return zone;
            if (!ctx.Events.IsValid) throw new ArgumentException("FishingContext.Events is not valid (use EventMods.Neutral).", nameof(ctx));
            if (!ctx.Skills.IsValid) throw new ArgumentException("FishingContext.Skills is not valid (use SkillMods.Neutral).", nameof(ctx));
            if (ctx.SubAreaIndex >= zone.SubAreas.Count)
                throw new ArgumentOutOfRangeException(nameof(ctx), "SubAreaIndex " + ctx.SubAreaIndex + " is not a sub-area of the zone (AnySubArea is gate-only).");
            return zone;
        }

        // clamp(junkChance * bait.JunkMult * (hotspot ? 0.5 : 1) * events.JunkMult, 0, 0.6); NaN gives 0
        private static float JunkShareOf(ZoneData zone, in FishingContext ctx)
        {
            float j = zone.SubAreas[ctx.SubAreaIndex].JunkChance * ctx.Bait.JunkMult
                      * (ctx.InHotspot ? EcologyConstants.HotspotJunkMult : 1f) * ctx.Events.JunkMult;
            if (!(j > 0f)) return 0f;
            return j > EcologyConstants.JunkShareCap ? EcologyConstants.JunkShareCap : j;
        }

        // Step 3 weight; 0 for specials, failed gates and non-positive or non-finite results (B-D3).
        private float PoolWeight(in SpawnRuleData rule, in FishingContext ctx, CatchLedger ledger)
        {
            if (rule.Special || !Passes(in rule, in ctx, ledger)) return 0f;
            FishSpeciesData s = _db.Fishing.Species[rule.SpeciesIndex];
            float w = rule.Weight;
            if ((s.Tags & ctx.Bait.AffinityTags) != 0) w *= ctx.Bait.AffinityMult;
            w *= ctx.Events.WeightFor(s.Tags) * ctx.Skills.RarityMult(s.Rarity);
            return w > 0f && !float.IsInfinity(w) ? w : 0f;
        }

        private CatchResult Fish(ushort speciesIndex, in FishingContext ctx, ref Pcg32 rng, out float weightT)
        {
            FishSpeciesData s = _db.Fishing.Species[speciesIndex];
            return CatchMath.RollFish(in s, speciesIndex, SaneLuck(ctx.Luck), ref rng, out weightT);
        }

        // Spec 12.4 step 6: one draw over the zone's junk weights, walked in order.
        private CatchResult JunkItem(ZoneData zone, ref Pcg32 rng)
        {
            IReadOnlyList<JunkEntry> junk = zone.Junk;
            float total = 0f;
            for (int i = 0; i < junk.Count; i++) if (junk[i].Weight > 0f) total += junk[i].Weight;
            float target = rng.NextFloat() * total, acc = 0f;
            int pick = 0;
            for (int i = 0; i < junk.Count; i++)
            {
                if (!(junk[i].Weight > 0f)) continue;
                pick = i;
                acc += junk[i].Weight;
                if (target < acc) break;
            }
            ushort index = junk[pick].JunkIndex;
            JunkData data = _db.Fishing.Junk[index];
            return CatchMath.Junk(index, in data);
        }
    }
}
```

### FishingRoller code (write exactly; pin: the a-b-c order)
```csharp
// Core/Ecology/FishingRoller.cs: the full cast roll on the resolver (C 7.6, M3-D13); replaces PlaceholderRoller.
// Authority: host only (FishingHostLedger at cast accept). Never sets FishingRoll.Pity (the ledger does; no draw).
// Fixed order (seeds depend on it): (a) item - resolver draws, or ForceJunk: one junk draw, or ForcedItemIndex: one RollFish draw
// (gates ignored, ruleIndex -1; B-D5); (b) BitePlanner.Plan (same draws as M2; ForcedBiteWait overwrites afterwards);
// (c) FightSeed = NextUInt (0 -> 1).
using System;

namespace FishGame.Core
{
    public static class FishingRoller
    {
        public static FishingRoll Roll(EcologyDatabase db, FishingResolver resolver, in FishingContext ctx, CatchLedger ledger,
                                       in RollOverrides overrides, int baitIndex, ref Pcg32 rng, out int ruleIndex)
        {
            if (db == null) throw new ArgumentNullException(nameof(db));
            if (resolver == null) throw new ArgumentNullException(nameof(resolver));
            FishingDatabase fishing = db.Fishing;
            if ((uint)baitIndex >= (uint)fishing.Baits.Count) throw new ArgumentOutOfRangeException(nameof(baitIndex));
            if (!ctx.Events.IsValid || !ctx.Skills.IsValid)
                throw new ArgumentException("FishingContext Events/Skills are not valid (use the Neutral values).", nameof(ctx));
            BaitStats bait = fishing.Baits[baitIndex];

            // (a) item
            CatchResult item;
            float t = 0f;
            ruleIndex = -1;
            if (overrides.ForceJunk)
            {
                item = resolver.RollJunkItem(in ctx, ref rng);
            }
            else if (overrides.ForcedItemIndex >= 0)
            {
                if (overrides.ForcedItemIndex >= fishing.Species.Count)
                    throw new ArgumentOutOfRangeException(nameof(overrides), "ForcedItemIndex is not a species index.");
                FishSpeciesData forced = fishing.Species[overrides.ForcedItemIndex];
                item = CatchMath.RollFish(in forced, (ushort)overrides.ForcedItemIndex, FishingResolver.SaneLuck(ctx.Luck), ref rng, out t);
            }
            else
            {
                item = resolver.Resolve(in ctx, ref rng, ledger, out t, out ruleIndex);
            }

            // (b) bite plan (B-D6)
            FishSpeciesData species = item.IsJunk ? default : fishing.Species[item.ItemIndex];
            float depth = float.IsPositiveInfinity(ctx.Depth) ? FishingConstants.DepthMultFullDepth : (float.IsNaN(ctx.Depth) ? 0f : ctx.Depth);
            float eventMult = ctx.Events.BiteTimeMult < EcologyConstants.EventBiteMultMin ? EcologyConstants.EventBiteMultMin
                            : (ctx.Events.BiteTimeMult > EcologyConstants.EventBiteMultMax ? EcologyConstants.EventBiteMultMax : ctx.Events.BiteTimeMult);
            float mult = BitePlanner.WaitMultiplier(bait.BiteSpeedMod, item.IsJunk ? 1f : species.BiteWaitMod, depth, eventMult, 1f, ctx.InHotspot);
            BitePlan plan = BitePlanner.Plan(in fishing.Tuning, mult, bait.MaxNibbles, ref rng);
            if (overrides.ForcedBiteWait > 0f)
            {
                plan.BiteWait = overrides.ForcedBiteWait; plan.NibbleCount = 0;
                plan.Nibble0 = 0f; plan.Nibble1 = 0f; plan.Nibble2 = 0f;
            }

            // (c) fight seed
            uint seed = rng.NextUInt();
            if (seed == 0) seed = 1;

            return new FishingRoll
            {
                Catch = item, WeightT = item.IsJunk ? 0f : t,
                BiteWait = plan.BiteWait, NibbleCount = plan.NibbleCount,
                Nibble0 = plan.Nibble0, Nibble1 = plan.Nibble1, Nibble2 = plan.Nibble2,
                FightSeed = seed,
                SizeClass = item.IsJunk ? (byte)0 : CatchMath.SizeClass(t),
                HookWindow = item.IsJunk ? 0f : (overrides.Twitchy ? 1.0f : species.HookWindow),
                Pity = false,
            };
        }
    }
}
```

```csharp
// Core/Ecology/DistanceField.cs: spec 12.5 two-pass chamfer (1 axis, sqrt 2 diagonal), cell units, centre to nearest land centre.
// Authority: none (pure maths; the editor bake calls it). +Infinity where there is no land at all.
using System;

namespace FishGame.Core
{
    public static class DistanceField
    {
        private const float Diagonal = 1.41421356f;

        public static float[] Compute(bool[] land, int width, int height)
        {
            if (land == null) throw new ArgumentNullException(nameof(land));
            if (width <= 0 || height <= 0 || (long)width * height != land.Length)
                throw new ArgumentException("land.Length must equal width * height (both > 0).", nameof(land));
            var d = new float[land.Length];
            for (int i = 0; i < d.Length; i++) d[i] = land[i] ? 0f : float.PositiveInfinity;

            // forward pass: rows z = 0..h-1, columns x = 0..w-1; neighbours W, N, NW, NE
            for (int z = 0; z < height; z++)
            {
                for (int x = 0; x < width; x++)
                {
                    int i = z * width + x;
                    float v = d[i];
                    if (x > 0) v = Math.Min(v, d[i - 1] + 1f);
                    if (z > 0)
                    {
                        int up = i - width;
                        v = Math.Min(v, d[up] + 1f);
                        if (x > 0) v = Math.Min(v, d[up - 1] + Diagonal);
                        if (x < width - 1) v = Math.Min(v, d[up + 1] + Diagonal);
                    }
                    d[i] = v;
                }
            }

            // backward pass: reverse order; neighbours E, S, SE, SW
            for (int z = height - 1; z >= 0; z--)
            {
                for (int x = width - 1; x >= 0; x--)
                {
                    int i = z * width + x;
                    float v = d[i];
                    if (x < width - 1) v = Math.Min(v, d[i + 1] + 1f);
                    if (z < height - 1)
                    {
                        int down = i + width;
                        v = Math.Min(v, d[down] + 1f);
                        if (x < width - 1) v = Math.Min(v, d[down + 1] + Diagonal);
                        if (x > 0) v = Math.Min(v, d[down - 1] + Diagonal);
                    }
                    d[i] = v;
                }
            }
            return d;
        }
    }
}
```

```csharp
// Core/Ecology/ShoreGridMath.cs: shore decimetres and reachability bits for the grid bake (spec 12.5, M3-D6, M3-D7).
// Authority: none (pure; ShoreGridBaker in the editor and the map validators call it).
using System;
using System.Collections.Generic;

namespace FishGame.Core
{
    public static class ShoreGridMath
    {
        // water cells: round(max(0, chamfer - 0.5) * cellSizeM * 10), capped at ShoreDmMax (no land at all: ShoreDmMax);
        // other cells: ShoreDmNotWater.
        public static ushort[] ShoreDecimetres(bool[] water, bool[] land, int width, int height, float cellSizeM)
        {
            if (water == null) throw new ArgumentNullException(nameof(water));
            if (!(cellSizeM > 0f) || float.IsInfinity(cellSizeM)) throw new ArgumentException("cellSizeM must be finite and > 0.", nameof(cellSizeM));
            float[] dist = DistanceField.Compute(land, width, height);
            if (water.Length != dist.Length) throw new ArgumentException("water.Length must equal width * height.", nameof(water));
            var dm = new ushort[dist.Length];
            for (int i = 0; i < dm.Length; i++)
            {
                if (!water[i]) { dm[i] = EcologyConstants.ShoreDmNotWater; continue; }
                float cells = dist[i];
                if (float.IsPositiveInfinity(cells)) { dm[i] = EcologyConstants.ShoreDmMax; continue; }
                double v = Math.Round(Math.Max(0.0, cells - 0.5) * cellSizeM * 10.0, MidpointRounding.AwayFromZero);
                dm[i] = v >= EcologyConstants.ShoreDmMax ? EcologyConstants.ShoreDmMax : (ushort)v;
            }
            return dm;
        }

        // A castable cell is reachable when its centre's horizontal distance to some stand point is in [minM, maxM] (M3-D6, any facing).
        public static byte[] ReachableBits(int width, int height, float cellSizeM, float originX, float originZ, byte[] castableBits,
                                           IReadOnlyList<float> standXZ, float minM, float maxM)
        {
            if (castableBits == null) throw new ArgumentNullException(nameof(castableBits));
            if (standXZ == null) throw new ArgumentNullException(nameof(standXZ));
            if (width <= 0 || height <= 0) throw new ArgumentException("width and height must be > 0.");
            int n = width * height;
            if (castableBits.Length != (n + 7) / 8) throw new ArgumentException("castableBits length must be ceil(w*h/8).", nameof(castableBits));
            if ((standXZ.Count & 1) != 0) throw new ArgumentException("standXZ holds x, z pairs.", nameof(standXZ));
            if (!(cellSizeM > 0f) || !(minM >= 0f) || !(maxM >= minM)) throw new ArgumentException("bad cell size or ring.");

            var bits = new byte[castableBits.Length];
            double min2 = (double)minM * minM, max2 = (double)maxM * maxM;
            int stands = standXZ.Count / 2;
            for (int cz = 0; cz < height; cz++)
            {
                double z = originZ + (cz + 0.5) * cellSizeM;
                for (int cx = 0; cx < width; cx++)
                {
                    int i = cz * width + cx;
                    if (!ShoreGrid.GetBit(castableBits, i)) continue;
                    double x = originX + (cx + 0.5) * cellSizeM;
                    for (int s = 0; s < stands; s++)
                    {
                        double dx = x - standXZ[2 * s], dz = z - standXZ[2 * s + 1];
                        double d2 = dx * dx + dz * dz;
                        if (d2 >= min2 && d2 <= max2) { bits[i >> 3] |= (byte)(1 << (i & 7)); break; }
                    }
                }
            }
            return bits;
        }

        // CountReachablePerSubArea and PackBits: see Behaviour.
    }
}
```

```csharp
// Core/Ecology/WeatherDirector.cs: spec 12.2 weather chain (R50). Host plain class; the track is a pure function of
// (table, season, runSeed), so DevWorldDriver rebuilds it on every Spot load (C 7.14).
// Planned track: rng = Rng.Stream(runSeed, "weather", 0); previous = Clear; 35 times previous = Next(previous) - so segment 0
// of day 1 is DRAWN from the Clear row. Day d >= 8: rng = Rng.Stream(runSeed, "weather", d), continuing from the previous segment.
// M3 produces only Clear, Rain, Fog (single bits).
using System;
using System.Collections.Generic;

namespace FishGame.Core
{
    public sealed class WeatherDirector
    {
        private const int MaxDay = 10000;
        private readonly WeatherTableData _table;
        private readonly Season _season;
        private readonly ulong _runSeed;
        private readonly List<WeatherMask> _track;

        public WeatherDirector(in WeatherTableData table, Season season, ulong runSeed)
        {
            Validate(in table);
            if ((byte)season > (byte)Season.Winter) throw new ArgumentOutOfRangeException(nameof(season));
            _table = new WeatherTableData { Base = (float[])table.Base.Clone(), SeasonColumnMult = (float[])table.SeasonColumnMult.Clone() };
            _season = season;
            _runSeed = runSeed;
            int planned = DayClock.PlannedDays * DayClock.SegmentsPerDay;
            _track = new List<WeatherMask>(planned);
            Pcg32 rng = Rng.Stream(runSeed, EcologyStreams.Weather, 0);
            WeatherMask previous = WeatherMask.Clear;
            for (int i = 0; i < planned; i++)
            {
                previous = Next(in _table, season, previous, ref rng);
                _track.Add(previous);
            }
            Track = _track.AsReadOnly();
        }

        public IReadOnlyList<WeatherMask> Track { get; }

        public WeatherMask At(int day, int minute)
        {
            EnsureDay(day);
            return _track[(day - 1) * DayClock.SegmentsPerDay + DayClock.SegmentAt(minute)];
        }

        public void EnsureDay(int day)
        {
            if (day < 1 || day > MaxDay) throw new ArgumentOutOfRangeException(nameof(day));
            while (_track.Count < day * DayClock.SegmentsPerDay)
            {
                int next = _track.Count / DayClock.SegmentsPerDay + 1;                 // the first missing day (>= 8), in order
                Pcg32 rng = Rng.Stream(_runSeed, EcologyStreams.Weather, (ulong)next);
                WeatherMask previous = _track[_track.Count - 1];
                for (int s = 0; s < DayClock.SegmentsPerDay; s++)
                {
                    previous = Next(in _table, _season, previous, ref rng);
                    _track.Add(previous);
                }
            }
        }

        public static void RowProbabilities(in WeatherTableData t, Season s, WeatherMask current, float[] into3)
        {
            if (into3 == null || into3.Length < 3) throw new ArgumentException("into3 needs 3 slots.", nameof(into3));
            Row(in t, s, current, out into3[0], out into3[1], out into3[2]);
        }

        // One NextFloat: [0, pClear) Clear, [pClear, pClear + pRain) Rain, else Fog.
        public static WeatherMask Next(in WeatherTableData t, Season s, WeatherMask current, ref Pcg32 rng)
        {
            Row(in t, s, current, out float pClear, out float pRain, out float _);
            float u = rng.NextFloat();
            if (u < pClear) return WeatherMask.Clear;
            if (u < pClear + pRain) return WeatherMask.Rain;
            return WeatherMask.Fog;
        }

        // Same formula as the EcologyRunState constructor (B-D8): one draw.
        public static Season RollSeason(ulong runSeed)
        {
            Pcg32 rng = Rng.Stream(runSeed, EcologyStreams.Season, 0);
            return (Season)rng.Range(0, 4);
        }

        // Row of the current weather: base x the season's column multipliers, then renormalised (spec 12.2). No allocation.
        private static void Row(in WeatherTableData t, Season s, WeatherMask current, out float clear, out float rain, out float fog)
        {
            if (t.Base == null || t.Base.Length != 9 || t.SeasonColumnMult == null || t.SeasonColumnMult.Length != 12)
                throw new ArgumentException("The weather table needs Base[9] and SeasonColumnMult[12].");
            if ((byte)s > (byte)Season.Winter) throw new ArgumentOutOfRangeException(nameof(s));
            int row = EcologyMasks.WeatherColumn(current) * 3, col = (int)s * 3;
            double a = (double)t.Base[row] * t.SeasonColumnMult[col];
            double b = (double)t.Base[row + 1] * t.SeasonColumnMult[col + 1];
            double c = (double)t.Base[row + 2] * t.SeasonColumnMult[col + 2];
            double sum = a + b + c;
            if (!(sum > 0.0) || double.IsInfinity(sum)) throw new ArgumentException("A weather row must sum to a finite value > 0.");
            clear = (float)(a / sum); rain = (float)(b / sum); fog = (float)(c / sum);
        }

        // B-D11: Base 9 finite entries >= 0 with every row sum > 0; SeasonColumnMult 12 finite entries > 0.
        private static void Validate(in WeatherTableData t)
        {
            if (t.Base == null || t.Base.Length != 9 || t.SeasonColumnMult == null || t.SeasonColumnMult.Length != 12)
                throw new ArgumentException("The weather table needs Base[9] and SeasonColumnMult[12].");
            for (int i = 0; i < 9; i++)
                if (!(t.Base[i] >= 0f) || float.IsInfinity(t.Base[i])) throw new ArgumentException("Base entries must be finite and >= 0.");
            for (int r = 0; r < 3; r++)
                if (!(t.Base[r * 3] + t.Base[r * 3 + 1] + t.Base[r * 3 + 2] > 0f)) throw new ArgumentException("Every Base row must sum to > 0.");
            for (int i = 0; i < 12; i++)
                if (!(t.SeasonColumnMult[i] > 0f) || float.IsInfinity(t.SeasonColumnMult[i])) throw new ArgumentException("Season multipliers must be finite and > 0.");
        }
    }
}
```

```csharp
            _rng = Rng.Stream(runSeed, EcologyStreams.Hotspot, (ulong)day);
            if (grid != null) grid.CollectReachableWaterCells(_cells);
            NextSpawnMinute = _cells.Count > 0 ? Draw(_t.HotspotFirstMinMin, _t.HotspotFirstMinMax) : int.MaxValue;   // (1)
        }

        public HotspotData Current { get; private set; }
        public int NextSpawnMinute { get; private set; }
        internal int DrawCount { get; private set; }

        public bool Advance(int minute)
        {
            HotspotData before = Current;
            while (true)
            {
                HotspotData c = Current;
                if (c.Active)
                {
                    if (minute < c.EndMinute) break;
                    Current = default;                                                     // ended at EndMinute
                    NextSpawnMinute = _cells.Count > 0 ? c.EndMinute + Draw(_t.HotspotGapMin, _t.HotspotGapMax) : int.MaxValue;   // (1)
                }
                else
                {
                    if (NextSpawnMinute == int.MaxValue || minute < NextSpawnMinute) break;
                    int cell = _cells[Draw(0, _cells.Count - 1)];                         // (2)
                    int duration = Draw(_t.HotspotDurationMin, _t.HotspotDurationMax);    // (3)
                    _grid.CellCentre(cell % _grid.Width, cell / _grid.Width, out float x, out float z);
                    Current = new HotspotData { Active = true, X = x, Z = z, Radius = _t.HotspotRadiusM,
                                                StartMinute = NextSpawnMinute, EndMinute = NextSpawnMinute + duration };
                    NextSpawnMinute = int.MaxValue;
                }
            }
            return !Same(in before, Current);
        }

        // Dev "spawn hotspot here": replaces Current (and any pending spawn), duration = DurationMax, no draws.
        public HotspotData ForceAt(float x, float z, int minute)
        {
            Current = new HotspotData { Active = true, X = x, Z = z, Radius = _t.HotspotRadiusM,
                                        StartMinute = minute, EndMinute = minute + _t.HotspotDurationMax };
            NextSpawnMinute = int.MaxValue;
            return Current;
        }

        public static bool Contains(in HotspotData h, float x, float z)
        {
            if (!h.Active) return false;
            double dx = (double)x - h.X, dz = (double)z - h.Z;
            return dx * dx + dz * dz <= (double)h.Radius * h.Radius;
        }

        private int Draw(int minInclusive, int maxInclusive)
        {
            DrawCount++;
            return _rng.Range(minInclusive, maxInclusive + 1);
        }

        private static bool Same(in HotspotData a, HotspotData b)
        {
            return a.Active == b.Active && a.X == b.X && a.Z == b.Z && a.Radius == b.Radius
                   && a.StartMinute == b.StartMinute && a.EndMinute == b.EndMinute;
        }

        private static void Validate(in EcologyTuning t)
        {
            bool ok = t.HotspotFirstMinMin >= 0 && t.HotspotFirstMinMax >= t.HotspotFirstMinMin && t.HotspotFirstMinMax <= MaxTiming
                      && t.HotspotGapMin >= 0 && t.HotspotGapMax >= t.HotspotGapMin && t.HotspotGapMax <= MaxTiming
                      && t.HotspotDurationMin >= 1 && t.HotspotDurationMax >= t.HotspotDurationMin && t.HotspotDurationMax <= MaxTiming
                      && t.HotspotRadiusM > 0f && !float.IsInfinity(t.HotspotRadiusM);
            if (!ok) throw new ArgumentException("EcologyTuning hotspot timings or radius are out of range.", nameof(t));
        }
    }
}
```

### JournalRules code (write exactly; pin: the Apply table)
```csharp
// Core/Journal/JournalRules.cs: spec 12.10 journal updates and hint levels (M3-D25, B-D15). Pure; no Unity types.
// Authority: local per peer (JournalRecorder applies every CatchAnnounced to the local save; T20).
// Apply table (fish only; junk, PityCast and None never journal and create nothing):
//   Lost:                       Seen++, spot added once
//   Landed / ReleasedCreelFull: Seen++, spot added once, CrewLanded++; and when localCatcher: Caught++ and bests
//   Bests: only a strictly heavier fish replaces them (weight, length, quality together).
//   FirstCatch = Caught went 0 -> 1. PersonalBest = an earlier catch existed AND the weight beat the old best.
using System;
using System.Collections.Generic;

namespace FishGame.Core
{
    public static class JournalRules
    {
        public static bool ShouldJournal(AnnounceKind kind, bool isJunk)
        {
            if (isJunk) return false;
            return kind == AnnounceKind.Landed || kind == AnnounceKind.Lost || kind == AnnounceKind.ReleasedCreelFull;
        }

        // null -> 0; the highest satisfied: Caught >= 3 -> 3, CrewLanded >= 1 -> 2, Seen >= 1 -> 1, else 0.
        public static int HintLevel(JournalEntry e)
        {
            if (e == null) return 0;
            if (e.Caught >= EcologyConstants.JournalCaughtForLevel3) return 3;
            if (e.CrewLanded >= 1) return 2;
            if (e.Seen >= 1) return 1;
            return 0;
        }

        public static JournalUpdate Apply(MetaSave save, string speciesId, string spotId, AnnounceKind kind, bool isJunk, bool localCatcher,
                                          int weightG, ushort lengthMm, CatchQuality quality)
        {
            if (save == null) throw new ArgumentNullException(nameof(save));
            if (string.IsNullOrEmpty(speciesId)) throw new ArgumentException("speciesId is required.", nameof(speciesId));
            if (!ShouldJournal(kind, isJunk)) return default;

            if (save.Journal == null) save.Journal = new Dictionary<string, JournalEntry>();
            if (!save.Journal.TryGetValue(speciesId, out JournalEntry e) || e == null)
            {
                e = new JournalEntry();
                save.Journal[speciesId] = e;
            }
            if (e.SeenInSpots == null) e.SeenInSpots = new List<string>();

            var u = new JournalUpdate { Changed = true, LevelBefore = HintLevel(e) };
            e.Seen = Inc(e.Seen);
            if (!string.IsNullOrEmpty(spotId) && !ContainsOrdinal(e.SeenInSpots, spotId)) e.SeenInSpots.Add(spotId);

            if (kind == AnnounceKind.Landed || kind == AnnounceKind.ReleasedCreelFull)
            {
                e.CrewLanded = Inc(e.CrewLanded);
                if (localCatcher)
                {
                    int caughtBefore = e.Caught;
                    e.Caught = Inc(e.Caught);
                    bool heavier = weightG > e.BestWeightG;
                    u.FirstCatch = caughtBefore == 0;
                    u.PersonalBest = caughtBefore >= 1 && heavier;
                    if (heavier)
                    {
                        e.BestWeightG = weightG;
                        e.BestLengthMm = lengthMm;
                        e.BestQuality = (byte)quality;
                    }
                }
            }
            u.LevelAfter = HintLevel(e);
            return u;
        }

        // CompletionCount: see Behaviour.

        private static int Inc(int v) => v < int.MaxValue ? v + 1 : v;

        private static bool ContainsOrdinal(List<string> list, string s)
        {
            for (int i = 0; i < list.Count; i++) if (string.Equals(list[i], s, StringComparison.Ordinal)) return true;
            return false;
        }
    }
}
```

### DayNightMath code (write exactly; pin: the blend window, the weights' smoothstep)
```csharp
// Core/Render/DayNightMath.cs: spec 10.3 day-night maths (M3-D24, B-D12..B-D14). Pure; called every frame by the
// DayNightController (T18), so nothing here allocates.
using System;
using System.Collections.Generic;

namespace FishGame.Core
{
    public static class DayNightMath
    {
        public const float ReadabilityDistanceM = 25f, ReadabilityMinFactor = 0.5f;
        private const double SunPeakElevationDeg = 60.0;
        private const float MinFlipWindow = 1e-6f;

        // Phase i holds from start[i]; the change into phase i runs over [start[i], start[i] + w_i] with smoothstep, where
        // w_i = min(window, nextStart - start[i]) (nextStart = 1 after the last phase). Continuous in dayFraction.
        public static PhaseBlend Blend(float dayFraction, IReadOnlyList<float> phaseStarts, float window)
        {
            if (phaseStarts == null || phaseStarts.Count == 0) throw new ArgumentException("phaseStarts needs at least one entry.", nameof(phaseStarts));
            float f = float.IsNaN(dayFraction) ? 0f : (dayFraction < 0f ? 0f : (dayFraction > 1f ? 1f : dayFraction));
            int i = 0;
            for (int k = 1; k < phaseStarts.Count; k++)
            {
                if (!(phaseStarts[k] > phaseStarts[k - 1])) throw new ArgumentException("phaseStarts must be strictly increasing.", nameof(phaseStarts));
                if (f >= phaseStarts[k]) i = k;
            }
            if (i == 0) return new PhaseBlend { From = 0, To = 0, T = 0f };
            float next = i + 1 < phaseStarts.Count ? phaseStarts[i + 1] : 1f;
            float w = Math.Min(window, next - phaseStarts[i]);
            float x = f - phaseStarts[i];
            if (!(w > 0f) || x >= w) return new PhaseBlend { From = i, To = i, T = 0f };
            return new PhaseBlend { From = i - 1, To = i, T = Smooth01(x / w) };
        }

        // Unit vector TO the sun. East (+x) at sunrise, south (-z) at noon, west (-x) at sunset; elevation
        // min + (60 - min) * sin(pi * p), p = progress through daylight, clamped to 0..1 outside it (B-D13).
        public static void SunDirection(float dayFraction, float sunriseFraction, float sunsetFraction, float minElevationDeg,
                                        out float x, out float y, out float z)
        {
            double span = (double)sunsetFraction - sunriseFraction;
            double p = span > 0.0 && !float.IsNaN(dayFraction) ? (dayFraction - sunriseFraction) / span : 0.0;
            p = p < 0.0 ? 0.0 : (p > 1.0 ? 1.0 : p);
            double minE = float.IsNaN(minElevationDeg) ? 0.0 : Math.Max(0.0, Math.Min(SunPeakElevationDeg, minElevationDeg));
            double elev = (minE + (SunPeakElevationDeg - minE) * Math.Sin(Math.PI * p)) * (Math.PI / 180.0);
            double az = Math.PI * p;
            double c = Math.Cos(elev);
            x = (float)(c * Math.Cos(az));
            y = (float)Math.Sin(elev);
            z = (float)(-c * Math.Sin(az));
        }

        // 1 by day; smoothstep fade over flipWindow after sunrise and before sunset; 0 at and outside the flips (B-D14).
        public static float SunWeight(float dayFraction, float sunriseFraction, float sunsetFraction, float flipWindow)
        {
            if (float.IsNaN(dayFraction) || !(dayFraction > sunriseFraction) || !(dayFraction < sunsetFraction)) return 0f;
            float w = flipWindow > MinFlipWindow ? flipWindow : MinFlipWindow;
            return Math.Min(Smooth01((dayFraction - sunriseFraction) / w), Smooth01((sunsetFraction - dayFraction) / w));
        }

        // 0 while the sun is up; smoothstep fade-in over flipWindow after sunset and fade-out before sunrise; 0 at the flips.
        public static float MoonWeight(float dayFraction, float sunriseFraction, float sunsetFraction, float flipWindow)
        {
            if (float.IsNaN(dayFraction)) return 0f;
            float w = flipWindow > MinFlipWindow ? flipWindow : MinFlipWindow;
            if (dayFraction >= sunsetFraction) return Smooth01((dayFraction - sunsetFraction) / w);
            if (dayFraction <= sunriseFraction) return Smooth01((sunriseFraction - dayFraction) / w);
            return 0f;
        }

        // ExponentialSquared: exp(-(density * distance)^2).
        public static float FogFactor(float density, float distanceM)
        {
            double k = (double)density * distanceM;
            return (float)Math.Exp(-k * k);
        }

        // FogFactor(density, 25) >= 0.5, i.e. density <= sqrt(ln 2) / 25 = 0.0333; NaN is never readable.
        public static bool IsReadable(float density)
        {
            return FogFactor(density, ReadabilityDistanceM) >= ReadabilityMinFactor;
        }

        private static float Smooth01(float x)
        {
            if (!(x > 0f)) return 0f;
            if (x >= 1f) return 1f;
            return x * x * (3f - 2f * x);
        }
    }
}
```
