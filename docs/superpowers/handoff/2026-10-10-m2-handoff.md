## Global constraints every M2 agent must get (lessons from M1)

- **Never `DEVELOPMENT_BUILD` or `#if DEBUG`** — Unity 6000.6 deprecates it (warning UAC0009). Use runtime `Debug.isDebugBuild` (`UnityEngine.Debug` if ambiguous).
- **The Write tool may decode `\uXXXX` escapes** in C# source. After writing any file whose intended text contains `\u`, check no byte > 0x7F unless the text itself is meant to be non-ASCII.
- **Cancel convention:** any cancel, including an already-cancelled token, faults with `NetworkSessionException(EndReason.UserLeft)` before any state change — never a Canceled task.
- **NetworkObject hashes:** after `OnValidate` in builders call `EditorUtility.SetDirty`, or `GlobalObjectIdHash` saves as 0.
- **Project settings via `SerializedObject`** when the API setter doesn't persist (e.g. `m_EnterPlayModeOptionsEnabled`).
- **Scene churn is accepted:** every BuildAll renumbers local fileIDs in `.unity` files with identical content. `git restore Assets/_Project/Scenes/*.unity` unless a scene really changed.
- **`core.autocrlf` is true;** committed blobs are LF, working tree may be CRLF.
- **EditMode tests can't reach Gameplay/Networking/App assemblies;** put testable rules in Core (pure C#) or test via PlayMode.
- **PlayMode fails on any unexpected `Debug.LogError`** and output must be warning-free; register `ISettings`/`IInputService` before a player spawns.
- **Late joiners during a scene load** get their player via `PlayerSpawner`'s `OnLoadComplete` hook — keep that path for every new scene transition.
- **Editor lock:** check `Temp/UnityLockfile` before batchmode; never kill Unity; ask the user to close the editor.
- **Sandbox refuses `rm -rf`** on project paths: use `git rm` / `git restore`, or ask the user.
- Commits: explicit paths, never `git add -A`; trailer names the model that wrote the change; work on a feature branch, merge with user consent.
